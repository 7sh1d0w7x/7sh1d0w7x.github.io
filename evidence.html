What an evidence pack looks like

2026-10-30 · artifact example · a lab VM, published in full

Most hardening reports are a PDF with a scanner screenshot. This is what I hand over instead: a directory of raw, re-runnable output, before and after, with hashes.

Every number on this page comes from a real lab VM (Ubuntu 26.04, KVM) that I hardened on October 30, 2026. The pack below is the actual artifact — nothing retyped.

The 11 checks

All read-only. Nothing on your host is modified, no packages are installed, and the whole run takes about ten seconds.

01  host identity ......... hostname, kernel, OS, uptime
02  sshd effective ........ permitrootlogin, passwordauth, maxauthtries, x11, allowusers
03  sshd drop-ins ......... every file in /etc/ssh/sshd_config.d
04  listening sockets ..... what the box actually exposes (ss -tulpn)
05  kernel sysctl ......... rp_filter, kptr_restrict, syncookies, ptrace_scope
06  firewall policy ....... nft / ufw / firewalld, or the absence of all three
07  sudo access ........... what each privileged user may run
08  uid 0 accounts ........ who is root besides root
09  SUID binaries ......... the setuid surface
10  cron .................. root crontab and /etc/cron.d
11  pending updates ....... how far behind the box is

Before / after, same host, four hours apart

Check                        before                after

Four rows changed out of ten. If a report shows every row improved, you are reading marketing — most settings were already correct, and saying so is part of the job.

Integrity: the pack proves it was not edited

Every file is hashed at collection time. Anyone can re-run the check and see whether the artifact was tampered with:

$ sha256sum -c SHA256SUMS
00-meta.txt: OK
01-host.txt: OK
02-sshd-effective.txt: OK
...
15 files, all OK

What is not in the pack

✗ private keys, hashes, passwords or tokens
✗ file contents from your home directory
✗ packet captures or traffic logs
✗ anything that requires write access

That is deliberate. The pack answers “what is enforced, what is listening, who is privileged, what is missing” — it does not need your data to do it.
