Read-only Linux health checks that find real problems, explain them in plain language, and remember what changed since last run. Open source. One command.

What it checks

Safe, read-only checks — it never modifies your system. Each finding comes with an explanation and a copy-paste fix.

Resources

Disk, memory, inodes, load — before they become an outage.

Services

Failed systemd units, containers that keep restarting.

Updates & security

Pending security patches, outdated kernels.

What changed

A plain “new / fixed” diff on every run — so you see drift early.
